# Working on Dispatcher

- Keep terminal creation and grouping independent of agent workflows. Isolate optional Codex runtime integration.
- Preserve explicit destination IDs, background creation, and uncertain-launch recovery. A successful terminal creation does not prove program startup.
- Do not launch sessions or change configuration merely for inspection.
- Keep initiative membership independent of UI grouping. Preserve the recorded backend and native identities through uncertain results; never infer membership from directory or title matches.
- The registry is local coordination state, not a sandbox. Native tools own execution and authentication; do not add another orchestration server.
